# Tasks

Conventions for every milestone:

- Milestones run bottom to top and each ends with a stop. Do not start the next milestone before the user approves the previous one. At each stop, report briefly what finished, which checks ran, and what comes next.
- Migrations are generated and applied by the user through `tools/` scripts; never run them without asking.
- Every test file named in this plan is part of the plan and is created as written; existing test modules are extended wherever the production subject already has one.
- Tests follow `AGENTS.md`: real DI from `di_for_tests()`, stubs from `test/stubs/`, existing fakes, no mocks of owned code. If a unit seems to need extensive mocking, advise the user before proceeding.
- Quality checks on every changed Python file: `pipenv run ruff check --fix <files>` and `pipenv run python tools/check_spacing.py --fix <files>`. Tests run offline with `pipenv run pytest <paths> -v`.
- Error code numbers named below are the next free ones at planning time; re-read `src/util/error_codes.py` and use the next free number in each category when implementing.
